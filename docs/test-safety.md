# LX 第三方音源验证安全约束

LX 源脚本由第三方维护，视为不可信代码。真实源测试只能使用本说明中的隔离边界；不得把通过搜索或拿到播放直链描述为完整播放验证。

## 环境隔离

- 每次验证使用新的临时数据目录、临时配置、日志和本地端口；不得复用生产 `.env`、`/data`、`sources-data`、NAS 持久卷、用户 LX 服务或其 Cookie/账户状态。
- LX 服务与 lxserver 应以无特权账号运行，监听 loopback；不挂载宿主目录、Docker socket、SSH 凭据、云元数据、系统配置或任意宿主敏感路径。
- 记录进程 PID、端口与临时目录，结束时只停止/删除本次创建并确认归属的测试资源；不得为了清理扫描或删改其他实例。
- 无法确认独立低权限运行环境时，不执行第三方脚本。不能以绕过安全边界来追求“全绿”。

## 脚本、网络和凭据

- lxserver `system.allowUnsafeVM` 必须保持 `false`。脚本要求 unsafe VM、导入/初始化产生不明确权限提示或疑似沙箱逃逸时，停止该脚本并记录 `unsafe_vm_required` / `blocked`，不得自动确认。
- 测试不得把生产密码、令牌、Cookie、已登录客户端配置或用户付费凭据写入脚本输入、命令行参数、日志或工件。无授权凭据时将需登录/付费权限的组合标为未验证。
- 只允许访问必要的公开脚本托管与音乐 API/CDN；拒绝 loopback、RFC1918、链路本地、云元数据和其他私网目标，逐跳重定向也重新检查。限制并发、请求超时和单个测试总时限。
- 不输出完整解析链接、查询签名、授权头、错误响应正文或脚本内容；结果仅保留仓库/提交、脚本 SHA-256、阶段、状态、耗时和媒体主机名。

## 测试边界与数据保留

逐阶段记录：脚本下载/哈希、导入初始化、平台声明、搜索、取链、媒体前缀读取、lxmusic-service URL 接口、代理 HEAD/GET/Range，以及音频解码或实际客户端播放。未执行的阶段必须写明，不得把上游直连结果当作项目代理播放成功。

媒体验证默认仅请求有界 Range 前缀（不超过 256 KiB）并做最多 2 秒的本地解码；除非测试明确获准且确有需要，不下载或保存整首音乐。测试产物脱敏后保留摘要报告即可；临时脚本、媒体字节、数据目录和进程状态按本次任务范围清理。

任何上游不可达、无权限、脚本失效或环境阻断应单独归因并标记失败/未验证；它们既不是项目通过证据，也不能直接归咎于项目代码。
